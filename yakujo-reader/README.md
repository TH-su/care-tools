# 薬情よみとり（事務所の Mac 専用）

薬情・お薬手帳のシール・調剤明細書の写真や PDF を、**事務所の Mac の中だけで**読んで、
入居者マスタの「📥 薬情の取り込み」で開く「結果のファイル」を作る道具です。

- 読むのは Apple の文字読み取り（Mac に組み込み）。**ネットにはつながず、外へは送りません。**
- 元の写真・PDF には触りません（消さない・動かさない・書き換えない）。
- 画面（ターミナル）には件数と時間だけを出します。氏名や薬の名前は出しません。

## 使い方

1. Finder で、ホームの「薬情よみとり」→「入れる」フォルダに、写真（HEIC・JPEG・PNG）か PDF を入れる
2. 「薬情よみとり」フォルダの **読む.command** をダブルクリック
3. 「できました」と出たら、「結果」フォルダが開く。入居者マスタの「📥 薬情の取り込み」から、その中のファイルを開く
4. 取り込みが終わったら、「入れる」フォルダの写真・PDF は消す（原本が別にあることを確かめてから）

初めて使う時だけ、このフォルダ（リポジトリの `yakujo-reader/`）の **読む.command** をダブルクリックします。
ホームに「薬情よみとり」フォルダ（入れる・結果）と、次から使う近道 **読む.command** ができます。

## 決まり

| 項目 | 中身 |
|---|---|
| 1回に読む数 | 20件まで（読んだ書類を「入れる」から外して、もう一度動かすと残りを読む） |
| 1ファイルの大きさ | 10MB まで |
| PDF のページ | 1つにつき10ページまで（それより後は読まず、結果と画面に知らせる） |
| 結果のファイル | 読んだ文字・位置・ページの画像（縮小）。**個人情報そのもの**なので、本人だけが読める権限で書く |
| 結果のファイルの消え方 | 24時間たつと、次にこの道具を動かした時に消える（本人の決定 2026-10-22）。動かさない間は残るので、取り込みが終わったら「結果」の中を消してもよい |
| Time Machine | 「薬情よみとり」フォルダを写しから外す（初回に自動で設定・管理者の権限は要らない）。Mac の中の一時的な写し（ローカルスナップショット）は外せないが、ふつう24時間ほどで消える |
| 写真の向き | 写真の情報（縦横）どおりに直してから読む。6000万画素を超える写真は読まない |
| PDF の入力欄・注釈 | 入力欄に書かれた文字・注釈も描いてから読む |

## 初回の準備（Mac に必要なもの）

Apple のコマンドラインツール（`swiftc`）が要ります。無い時は、ダブルクリックした画面に入れ方が出ます。
道具の本体（`yakujo-reader.swift`）は、初回と、本体が新しくなった時だけ、Mac の中で作り直します（ホームの「薬情よみとり/.道具」）。

## 結果のファイルの形（入居者マスタが読む）

```
{ "kind": "yakujo-yomitori", "v": 1, "createdAt": "2026-10-22T15:50:34+09:00",
  "reader": { "name": "薬情よみとり", "version": "1.1", "engine": "apple-vision", ... },
  "docs": [ { "no": 1, "file": "<元のファイル名>", "type": "photo|pdf", "error": "", "note": "", "pagesTotal": 1,
              "pages": [ { "no": 1, "w": 1200, "h": 900, "error": "", "img": "data:image/jpeg;base64,…",
                           "codes": { "qr": 0, "other": 0 },
                           "lines": [ { "t": "<読んだ文字>", "x": 0.04, "y": 0.20, "w": 0.30, "h": 0.02, "c": 1 } ] } ] } ],
  "skipped": [ { "file": "<元のファイル名>", "why": "<読まなかった理由>" } ] }
```

- 位置（x・y・w・h）は、ページの左上を原点にした 0〜1 の割合。行はおおよそ上から下・左から右に並ぶが、傾いた写真では崩れるので、**使う側は位置で組み直す**。
- PDF の `pagesTotal` は元のページ数。11ページ以上の時は、はじめの10ページだけを読み、`note` に書く。読めないページも番号を詰めずに入れ、そのページの `error` に理由を書く。
- `c` は読み取りの確からしさ（0〜1）。

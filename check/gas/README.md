# 現場からの報告の受け口（Google Apps Script）

`report-inbox.gs` は、全画面の「不具合を報告」ボタンと、画面のエラーの自動報告（`su-report.js`）と、
管理者の「画面の指摘」（`su-annot.js`）を受け取り、スプレッドシートに控えを残してから GitHub の Issue（ラベル「現場報告」）にします。

> すでに置いてある受け口を新しい版にする時: Apps Script の中身を貼り替えて保存し、デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ。
> URL は変わらないので、端末の設定はそのままで使えます。

## 置き方（1回だけ・代表者の作業）

1. Google スプレッドシートを新規作成（名前は自由。例「不具合報告の受け口」）
2. 拡張機能 → Apps Script → `report-inbox.gs` の中身を貼る
3. 左の歯車「プロジェクトの設定」→ スクリプト プロパティ

   | 名前 | 値 |
   |---|---|
   | `SECRET_K` | 受け口の合言葉（長い無作為な文字列。**英数字だけ**。記号を入れると URL の読み取りで食い違う） |
   | `GITHUB_TOKEN` | GitHub の Fine-grained personal access token（対象: care-tools のみ／Issues: Read and write） |
   | `GITHUB_REPO` | `TH-su/care-tools` |
   | `MAX_PER_DAY` | 1日に作る Issue の上限（省略時 20） |

4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行ユーザー「自分」／アクセスできるユーザー「全員」
5. 事務所端末の **接続設定 →「不具合の報告先」** に、出てきた URL を「接続先のURL」、`SECRET_K` を「合言葉」に入れて保存
   - 「接続を確認」は URL が受け口かだけを見ます（合言葉は送りません）。合言葉が合っているかは、報告画面の「そのまま送信」で「送信しました」と出るかで分かります（違うと「受け付けられませんでした」）
   - 「控えを作る」で控え（SUCFG1:）を作り直すと、他の端末にも「控えから戻す」で配れます。現場用に設定した端末は接続設定を開けないので、いったん事務所用に切り替えてから戻し、終わったら現場用へ戻します

## 届いた後の流れ

```
現場の端末 ──送信──▶ 受け口GAS ──▶ 受信シート（控え）
                               └──▶ GitHub Issue「現場報告」
                                        └──▶ 夜 23:00 の定期タスクが読む → 再現 → 直す → 下書き PR
                                                 └──▶ 翌朝、代表者が PR を見て取り込む
```

## 守っていること

- 合言葉（`?k=`）が合わない送信は捨てる。本文は 8000 文字で切る
- 同じ自動報告（同じ画面・同じエラーの種類と場所）は、開いている Issue へのコメントにまとめる（6時間に1回まで）
- 1日の Issue 作成数に上限がある（嵐になっても止まる）
- 職員の自由記述は Issue の題名に入れない。本文は「○○様」「○○さん」「○号室」の形を伏せてから載せる（Issue は公開リポジトリに載るため。氏名の一覧は持たないので完全ではなく、画面側でも「書かない」と案内している）
- 本文は Markdown として効かない形で載せる（``` を置き換える）。シートに書く値は数式として解釈されない形にする
- GitHub に届かなくても受信シートには残る
- 「画面の指摘」の配置図は、数値と色（rrggbb）だけの形かを確かめ、数値から作り直したものだけを Issue に載せる（形が違えば載せない）。
  配置図はシートには残さない（本文の文字だけを残す）。配置図の絵は、Issue ができた後に GitHub Actions（`.github/workflows/report-image.yml`）がコメントで付ける

## 自分で試す

受け口 URL に `?k=<SECRET_K>` を付けた先へ、次の文字をそのまま POST すると Issue が1件できます。

```
【不具合報告】2026/10/4 10:00:00
ツール: 介護ツール メニュー（index.html）
症状: 受け口の試し（このIssueは閉じてよい）
──── ここから下は自動で付いた情報です ────
端末: Mac / Chrome / 画面 1280×800（倍率2）
役割: 事務所端末 ／ 接続: 設定あり
版: 記載なし ／ この画面を開いてから 0分
画面のエラー: なし
```

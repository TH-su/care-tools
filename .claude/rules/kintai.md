# 勤怠管理 の決まり（CLAUDE.md §3 から移した・文は一字一句そのまま）

このファイルは、上の paths のファイルを Read・Edit・Write した時に読まれる。grep・sed だけで触る時は、触る前にこのファイルを読む。全画面に効く決まり（§1・§2・§4〜§10 と §3 の横断の項目）は CLAUDE.md にある。

- 勤怠管理（`kintai-clock.html`・`kintai.html`）の決まり（凍結した仕様 2026-11-18〜20 の要点・本人指示 2026-11-21 でここへ移した）:
  - 正本は共通 DB（統合 0098〜0101・0104・0106〜0109・0111〜0115・0117・0120）だけで、Google（GAS）は使わない。表は直接は誰も読めず書けず、データベースの関数だけが読み書きし、誰が何をできるかも関数が決める（画面では決めない）。職員の軸はシフトの職員ID（職員マスタから足した人も同じ表・0106）で、給与と結ぶ鍵は従業員コード。事業所の区分は施設・訪問・通所の3つで、名前は `SUFacility` から出す。打刻の端末に事業所・接続先を設定させない（事業所は予定との突き合わせで決まる）。
  - 打刻の画面は現場・事務所・管理者が開ける（`SUAppGate` の kintai-clock）。現場に許すのは、名簿（名前と事業所だけ）・番号の引き当てと照合・打刻・今日の打刻の履歴だけで、番号・全件の名簿・詳細は返さない。番号を続けて違えると、しばらく止める。
  - 管理画面は「現場端末の止め → `SUAppGate.run('kintai')`」の順で開き、データベースは管理者（2段階認証）と勤怠の名簿（0104）に載せた事務所のアカウントだけを通す。
  - 生の打刻は変えない（消さない・書き換えない）。直しは事務所が足す打刻と理由つきの取り消し（印を付けるだけで行は残す）で行い、早出・残業の承認・休憩の直し・メモと一緒に、全部を直しの履歴に理由つきで残す。
  - 打刻の時刻はデータベースの時計で決める（端末の時計を信じない）。通信できない時は端末に控え、つながったら送り、端末の時刻に「控えから」の印を付けて要確認に出す（72時間より古い・5分より未来は断る）。同じ控えの送り直しは1件にまとめる。日付と深夜の判定は日本時間に固定。
  - 丸め: 予定より早い出勤は予定の開始から、予定より遅い退勤は予定の終わりまで数える。早出・残業を承認した日は打刻どおり（「この時刻から／この時刻まで認める」の承認はその時刻まで）。遅刻・早退・予定の無い勤務も打刻どおり。数えるのは分までで、切るのは1分未満（秒）だけ。5分・15分などの単位で切り捨てない（日ごとに働いた時間を短くするため・基発150号）。丸めの単位の設定（既定1分＝丸めない）は、働いた人に有利な向き（遅刻の出勤の切り捨て・早退の退勤と承認した残業の終わりの切り上げ）にだけ効かせ、丸めた値が丸めない値より短くなる日は丸めない。予定から境目（既定30分）以上ずれた打刻は要確認に出し、事務所が認めるかを決める。丸めた時刻は「数えた時刻」として別に出し、画面には生の打刻を必ず並べる。
  - 休憩の決まり（境目の時間・休憩の時間・夜勤の休憩）はシフトアプリの設定が正で、勤怠の設定には持たない。休憩は拘束が境目を超える時だけ引く（ちょうどは引かない）。法定外は1日・週（変形なし）・期間の総枠（1か月単位の変形労働時間制）で数える。
  - 月は締め日（設定・0＝月末）で切り、「〇月分」の期間で数える（0101）。締めた月分は打刻の追加・取り消し・日の直し・予定の取り込みを断り、締めた時の設定で数える。打刻そのものは締めた後も受けて要確認に出す。締めの解除は管理者だけで、給与を確定・書き出した月分は解除できない（給与の 0103）。
  - 要確認が残る月分は締めない。締めの窓と「締める」を押して読み直した後の両方で止め、データベースの締め（0120）も控えに要確認の残る職員がいれば断る。早出・残業は1件ずつ「認める（打刻どおり）／認めない（予定の時刻で切る・理由が要る）」を決め、認めない理由は日の行（early_ng・ot_ng・200字まで）と直しの履歴に残す。認めないは数える時間を変えない（今の丸めのまま）。認めない理由と「全部認める」は同じ日に並べず、理由を送らずに全部認めた時は認めないの方を外す。「この時刻から／まで認める」とは並べてよく（分割勤務の日）、決める窓は時刻で区切って認めてある日に「認める」を出さない（日全体の承認に広がるため）。早出・残業が「まだ決めない」の日は、直す窓の「確認済み」で要確認を外させない。打刻の漏れは今までどおり打刻を足す・欠勤・確認済みで解く（本人指示 2026-11-21・文と位置は仮置き）。
  - 給与向けの CSV（月の集計・日ごと）は、従業員コードが空の人を出さずに警告する。文字コードは UTF-8（BOM 付き）と Shift_JIS を選べる。日ごとの明細の末尾に「数えなかった時間」（打刻のうち数えた区間の外の分・人ごとの合計は集計の同じ列と同じ）と「数えなかった理由」（認めないと決めた早出・残業の理由）を出す（0120）。
  - 有給は入職日からの付与・2年の期限・古い付与から使う順・年5日の取得義務を `kintai-leave.js` が数え、データベースは記録と権限だけを持つ（0106）。年次有給休暇管理簿（`kintai-ledger.js`）の残りは `kintai-leave.js` の残りをそのまま使い、数え方を二つに分けない。
  - 休暇の種類は、時間単位の有休（1時間単位・年5日分まで・年5日の取得義務には数えない）・特別休暇・代休・振替休日を記録できる。消さずに取り消しの印で直す（0113）。
  - 勤怠で出す名前は、シフトの氏名を書き換えずに表示名として別に持ち、無ければシフトの氏名を出す（0107）。職員マスタとつないだ人の打刻の番号は職員No の頭に 0 を付けた4桁、従業員コードは頭の A を抜いた4桁にそろえ、空なら職員No から埋める。この決まりはデータベースの書く前の1か所だけに置く（0108・0109・代表者の指示 2026-11-20）。
  - 出勤予定は勤怠の画面でも直せ、シフトに載らない職員の予定も入れられる。手直しはシフトの取り込み直しで消えない別の記録に置き、職員ごとの固定時間の前提は版で持つ（消さない・書き換えない・直す時は前の版に取り消しの印を付けて新しい版を足す・0111・代表者の依頼 2026-11-20）。
  - 勤怠の名簿は管理者（2段階認証）が勤怠の画面の設定で直す。給与の名簿に載っている人は外せない。有給の付与の足し・取り消しも、使用と同じく締めた月分では断る（0112）。
  - 締めた月分は、その初日の前の7日（週40時間の数えに使う日）も直さない（締めた月の法定外が後から変わるため）。事務所が足す打刻は二度押しても1行にし、職員の取り込み・設定の保存・予定の取り込みも直しの履歴に残す（0117・代表者の決定 2026-11-20）。
  - 36協定（`kintai-36.js`）は、法の上限（法定外と休日労働の合計が月100時間以上・2〜6か月の平均が80時間超）を設定と切り離して常に判定し、月の30分の丸めの前の値で比べる。法定休日を決めていない時は休日労働を数えられないので、休日労働を含む項目に「少なく出ています」を足す。勤務の決まりの見張り（`kintai-rules.js`）は知らせだけで、数えた時間・給与へ渡す値は変えない。
  - 自分の勤怠（`kintai-self.html`）は職員本人のスマホの画面で、共通ログイン（`su-auth.js`）・許可リスト・現場のアカウントに乗らない（この画面から入居者の画面へは入れない）。登録は、管理者（2段階認証）が勤怠の画面で出す1回限り・10分の登録の番号と、本人が決める4桁の暗証番号で行う。端末に置くのは受け口が作った鍵とタブの印だけで、暗証番号・開いている印・勤怠・有給・申請・表示名はメモリだけ（閉じる・2分さわらない・登録を外す時に捨てる）。データベースは鍵のハッシュだけを持ち、職員は毎回その鍵から決める（画面の名乗りを信じない）。暗証番号を続けて違えると止まる。数え方は管理画面と同じ部品（`kintai-calc.js`・`kintai-leave.js`）を使う。画面だけで印刷しない。申請（打刻の直し・残業と早出・月の勤怠の確認）を承認するのは勤怠の管理者（0114）。
  - 社会保険の加入の知らせ（`kintai-shaho.js`・設定の鍵 shaho・既定は切）は知らせだけで、加入の手続き・数えた時間・給与の計算は変えない。切の間は「社保」のタブもホームの箱も出さない。基準は4分の3基準（既定）と短時間労働者の要件（特定適用事業所）から選び、しきい値は設定のタブで直す。月の時間は月×12÷52 で週へ直し、実績が続けて（既定2か月）基準以上なら要対応、1か月か予定だけなら注意。対象外（加入済み・役員・学生など）は管理者が一覧で決める（shaho.exempt）。給与の設定は、そのログインで給与の鍵が開いている時だけ payroll_bootstrap で読み、加入済みか・役員か・月額の見込みだけを取り出して10分で捨てる（覆いも暗証番号の窓も出さない・金額は画面に出さず「以上／未満」だけ・端末に残さない）。読めない時は「未判定」（2026-11-25・文と既定は仮置き）。

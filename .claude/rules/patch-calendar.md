# 貼り薬カレンダー の決まり（CLAUDE.md §3 から移した・文は一字一句そのまま）

このファイルは、上の paths のファイルを Read・Edit・Write した時に読まれる。grep・sed だけで触る時は、触る前にこのファイルを読む。全画面に効く決まり（§1・§2・§4〜§10 と §3 の横断の項目）は CLAUDE.md にある。

（CLAUDE.md §3「施設ごとの値の塊は `SUFacility.section(名前)` で読む」の中にあった項目）
  - 貼り薬カレンダーの薬の名前と貼る場所は、patchCalendar（drug＝薬の名前・sites＝貼る順の場所2〜8か所）を書いた時だけ差し替え、9か所以上（保存の番号は 1〜8 だけ）・1つでも崩れていれば丸ごと捨てて今の1種類・背中8箇所のまま。場所を書いた時は背中の写真の図でなく番号の枠と名前の図を描く。drug・sites は既定（1番）の種類で、patchCalendar.kinds（no＝種類の番号 2〜8・重ならない・drug は必ず・sites は書けば2〜8か所・1つでも崩れれば kinds だけ捨てて帯で知らせる）を書いた施設だけ、入居者を選ぶ欄のすぐ下の「貼り薬の種類」（スクリプトで作る・画面だけ）で入居者ごとに種類を選べる。入居者ごとの種類は共通 DB の関数・表を変えず、同じ控え（apc2_res）と patch_put の別の鍵の行に置く（`<入居者ID>:pkr`＝別の種類の設定・`<入居者ID>:pkb`＝別の種類へ替えた時の既定の行の写し（形も中身も既定の行と同じ）・`<入居者ID>:pk`＝選びの行。★選びの行の site_no は「種類の番号」、start と prev_no は選んだ設定の開始日と貼る場所の番号＝指紋という列の意味の流用。共通 DB や書き出しを直接見る時に貼る場所と取り違えない）。指紋が設定の行と合う時だけその種類で表示し、合わない・種類が施設情報に無い・別の種類の方の既定の行が写しと値で違う（日時では比べない）時は既定に倒さず未設定（仮の値）と警告。警告の方は、人が「貼り薬の種類」で選んだ時だけ保存する（欄が出ない時は「保存できません」と出す）。写し→設定の行→選びの行の順に同じ日時で送る。kinds の施設では、事務所PCで方を選んだ時と印刷の前に1回読み直す。kinds の施設の現場の端末では印刷しない（ボタンは「事務所PCで印刷してください」と知らせて止め、Cmd/Ctrl+P・共有メニューの印刷でも紙にはその知らせだけを出す。現場の端末で施設情報がまだ読めない時も、Cmd/Ctrl+P の紙は施設情報が読めない知らせだけにする。現場の端末はほかの端末で替えた種類を受け取らないため・代表者の決定 2026-11-18・文は仮置き）。選びの行の無い方・kinds を書いていない施設は今のまま（控え・送る中身・印刷の確かめの鍵・紙は今と同じ）。手入力の別の種類は apc2_mkind・apc2_m2（送らない・手入力の種類が1番でない時は手入力の設定を書き出さない）。書き出し・読み込みは行ごとの上限で確かめ、読めなかった行は黙って落とさず知らせる。名簿に入居者ID が :pk・:pkr・:pkb で終わる方がいれば種類の機能を止める（帯と、別の種類に替えてあった方を確定にしない注意は kinds を書いた施設だけ）。kinds の施設では、写しの見比べと未送信の一覧が :pk・:pkr・:pkb の行も1件と数える（直さない）。行は消せないので既定の種類へ戻した方も選びの行（種類 1）を書く。配る順は 画面を配る→全端末を読み込み直す→施設情報の Secret に kinds を書く。試験は `check/unit/patch_kind_test.js`・`check/patch_config_e2e.mjs`（代表者の決定 2026-11-17 案A・文言と位置は仮置き）。保存の形・送る中身・現場端末の動き・patch_read は変えない。印刷の前に施設情報を待ち、読めなければ刷らない。施設情報が読めず端末の控えも無い時は、見出しの下に帯で既定の貼る場所で表示していることを知らせる（保存は止めない・画面だけ）。試験は `check/unit/patch_config_test.js`・`check/patch_config_e2e.mjs`（代表者の決定 2026-11-13）。貼る前の確かめ（check/facility-secret-check.mjs）は、画面の読み方の関数（pcCfgOf・pcKindsOf）を切り出して同じ決まりで drug・sites・kinds を確かめ、崩れていれば止める（2026-11-18・第8回の監査の気づき2）。

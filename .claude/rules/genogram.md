# 家族構成図 の決まり（CLAUDE.md §3 から移した・文は一字一句そのまま）

このファイルは、上の paths のファイルを Read・Edit・Write した時に読まれる。grep・sed だけで触る時は、触る前にこのファイルを読む。全画面に効く決まり（§1・§2・§4〜§10 と §3 の横断の項目）は CLAUDE.md にある。

- 家族構成図の絵は、家族構成図アプリが保存した時に、入居者マスタから開いた方（masterId のキーを書けた時）の分だけ共通 DB へ送り（geno_thumb_put）、フェイスシート・入居者マスタは事務所の画面で、ログインしている時だけ読んで（geno_thumb_get）、端末の控えより新しい時だけ枠の中身を差し替える（読んだ絵は端末に保存しない）。氏名キーだけの保存と、クラウドの食い違いで中止した保存は送らない。送る絵は100万字に収め（超える時は送る絵だけ縮める）。消すのは管理者だけ（geno_thumb_del・端末に masterId のキーが無い時は名簿で1名にだけ一致した方）。切り替えスイッチは置かず、関数が無い間は今までどおり端末の控えだけで出す。ログインしていない端末で保存した時は「ほかの端末には出ません」と知らせる（統合 0056・代表者の決定 2026-11-03）。フェイスシートの家族構成図の絵は、PC・MacBook（幅900px以上）と紙では今の面積の約6分の1（縦横とも約41%・画面は高さ360pxまで・紙は85mmまで）にし、絵がある時は枠も絵に合わせて低くする（絵が無い枠は今の高さのまま）。iPhone・iPad 縦は今のまま（本人指示 2026-11-03）。フェイスシートの「家族・事業所」は、PC・MacBook（幅900px以上）と紙では、家族情報の4項目の行の下を左に事業所・右に家族構成図（横幅の40%）の横並びにし、家族情報と事業所の境目を太線にする（家族構成図は家族情報の一部・事業所は別の欄と分かるように）。iPhone・iPad 縦は縦に積む（家族情報 → 家族構成図 → 事業所）。「家族情報」を印刷しないにした時は家族構成図も紙に出さない（本人指示 2026-11-03）。「全体を印刷」では、家族情報の4項目の行と事業所・家族構成図の行を1つの塊として改ページで分けない（家族情報だけが前のページに残って家族構成図と離れないように・1人分の印刷と同じ形・塊が1ページより高い時は途中で分かれる）（代表者の決定 2026-11-14）。
- 家族構成図は、フェイスシート・入居者マスタ・「この方の画面：」から URL で番号（?resident=）だけを受け取り、氏名は共有名簿（su_residents_common）でその番号の1名から引く。古い URL の ?name= は起動したらすぐ URL から消す（代表者の決定 2026-11-13）。引けない時は名前の欄を空にして帯で知らせ、前回の図・下書きを開かない。古い URL の氏名は名簿に無い時だけ使う（この2つは仮置き）。現場の端末のフェイスシート（安全情報だけの表示）には家族構成図の枠を出さない（今のまま・代表者の決定 2026-11-03 とそろう）。
- 家族構成図は、起動の時と画面が見えている間1時間ごと（隠れている間は休む）に同期の受け口へ確かめ（ping）を送り、答えの auth が "ok" 以外の時はほかの端末との一覧・読込・保存・削除を止めて、消せない帯（画面だけ・印刷しない）で知らせる。通信の失敗・合言葉の断りでは止めない。端末の控えでの表示・編集・保存は止めず、止めた保存は保留に積まずに次の保存でクラウドと突き合わせる。家族構成図の絵を共通 DB へ送る道は対象外（代表者の決定 2026-11-13）。

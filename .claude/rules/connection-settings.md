# 接続設定 の決まり（CLAUDE.md §3 から移した・文は一字一句そのまま）

このファイルは、上の paths のファイルを Read・Edit・Write した時に読まれる。grep・sed だけで触る時は、触る前にこのファイルを読む。全画面に効く決まり（§1・§2・§4〜§10 と §3 の横断の項目）は CLAUDE.md にある。

- 接続設定の初回の案内は、段ごとに「合言葉も確かめる」を出し、この端末に保存した合言葉を読むだけの ping（本文・text/plain）で送って、本文の印（unauthorized・認証エラー・code:403）と本当の 403 を「合言葉が違います」と出す。決まった形でない答えと、ping の口の無い系統（排泄ケア記録・体重管理・不具合の報告先）は送らずに「確かめられません」と出す。統合同期と入居者マスタは、先に合言葉なしで別のアプリと分かったら合言葉を送らない。持ち主の画面の確かめ（liveReady／probe）が「ログインだけで使える」と答えた系統（入居調整・計画書・家族構成図・過去シフトの4つだけ）は ✕ にせず「ふだんの読み書きはログインで使えます」と、系統ごとに接続先が要る場面（計画書＝AI の下書き・閉じる直前の送信・管理者が戻す時、入居調整＝添付書類・管理者が戻す時、家族構成図・過去シフト＝管理者が戻す時。管理者の端末には入れておく）を添える。段は飛ばさず ✓ にもしない（下の欄は隠さない・画面だけ・代表者の指示 2026-11-13・同日の反証レビューで段を飛ばさない形にした・文は仮置き）。見るだけの合言葉（家族構成図の閲覧用・過去シフトの読むだけ）は ✕ にせず △「合言葉は通りました（見るだけの合言葉です。…）」と出す。
